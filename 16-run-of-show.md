## If something fails
Audio: reduce to the prepared backup player/mix, keep manual volume control.  
TV: use the single local forest-loop fallback; if unavailable, a static forest image is fine.  
Lights: restore saved static scene.  
Guardian: remove it if unstable; the backdrop and light carry the room.  
Story: skip it.  
Noise complaint: lower volume/bass immediately; host responds personally.  
Crowding: pause additional arrivals and clear routes; do not use the hallway as overflow.

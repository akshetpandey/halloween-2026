# The First Knock

Original procedural model and animation authored October 31, 2026 for Hollow Court (MAKE-01). Editable source: [build-twig-spirits.mjs](../../../../scripts/guardian-models/build-twig-spirits.mjs). [Identity and performance brief](../../../../twig-spirits-2026-10-31.md).

The host's actual handmade prop guides the silhouette, wood/flax palette and bindings. Current private reference photographs were viewed locally; no private photograph pixels, scan geometry, room background, guest data, downloaded model or third-party texture is included. Unseen sides are a stylized interpretation. The assets contain original code-generated closed geometry, vertex colors and five authored local-joint clips, with no external resources. Three.js is the existing MIT-licensed authoring/export dependency.

Rebuild from the app folder with `node scripts/guardian-models/build-twig-spirits.mjs`. +Y is up, +Z is front. The normalized craft can be staged by the shared runtime. `Idle` and `Greet` loop for 2.4s; `Awaken` 0.9s, `Play` 3s and `Settle` 1s are once-only. See provenance.json for exact checksum and measured resource counts. Physical-phone performance and host appearance acceptance remain separate gates.

# Phone-first puzzle revision — September 9, 2026

Status: Implemented for host review following direct puzzle feedback. This supplements [the family contract](puzzles.md); timings and real-phone comfort remain to playtest. Story, Favors, routes and physical pairings retain their existing scope.

## Design choices and feedback coverage

| Guardian / family | Revised behavior |
|---|---|
| All encounters | Compact 80px portrait beside the guardian name on a 390px phone viewport; puzzle begins around 324px from top. Instructions use 16px DM Sans, reset appears above the puzzle and submission actions stay accessible. Desktop illustration column is reduced to 170px. |
| Gilded Root / Missing Sigil | Four answer cards in a 2×2 grid, each showing the actual mark and dot count. |

| Unfinished Guest / Broken Seal | Six shards in a 2×3 edge-matching puzzle. Matching runes meet; blank edges face outward. The top-left shard anchors orientation. Player places and rotates five loose shards. Enumerated completion is unique. |
| Black Correspondent / Hidden Token | First cup physically lifts, reveals the acorn, lowers before five swaps, then the chosen cup lifts at submission. A wrong guess also reveals where the acorn ended. Replay uses the same sequence. |
| Very Certain Owl / Three Witnesses | Three statements about Fox, Hare and Raven carrying three different marks. Exactly two statements are true and one is false. Includes left-of/beside relationships, asks for the complete arrangement, and checks all six possible assignments for uniqueness. |
| Fox / Rule of Three | Actual polygon groups replace text-only examples and answers. Infer a numerical relationship between edge counts from accepted/refused examples; the curated rules include average, sum and fixed total. Examples distinguish the supported rules; only one answer qualifies. |
| Stag / Path Through Thorns | A 5×6 wall maze with dead ends, alternate routes and thorn patches. Reach the exit through exactly the stated number of thorn cells. A valid route has at least twelve cells; all simple routes are enumerated and only one meets the target. Tap or drag, with backtracking/undo. |
| Hare / Turning Wheel | Clockwise, counterclockwise, clockwise: three stated operations. Avoid cancellation to the original wheel and trivial identical adjacent turns. |
| Ember / Offering | Six different values drawn from 4–15. Choose three to hit a target near the middle of possible totals. Exactly one combination works, with close distractor totals rather than powers of two. |
| Knotkeeper / Untangle | Seven stones and twelve threads; at least six initial crossings. Removing any one stone's incident edges still leaves a crossing, proving that moving only that stone cannot solve the start. |

## Typeface and spacing

Headings use locally served **Cormorant Garamond**; body/UI text uses **DM Sans**. The first build applied custom negative letter-spacing (up to −2px), which crowded the serif/italic letterforms. That tightening is removed and normal font kerning is explicit. Small uppercase labels retain intentional positive tracking. No new font dependency or remote font service.

## Validation and versioning

Version 2 generators are deterministic from event/player/guardian/version. Preview assignments upgrade once on opening a guardian; earned Favors and short routes remain untouched. Reloads and resets then preserve the revised instance. Existing live assignments are not automatically replaced. Old seal/graph renderers remain compatible with earlier stored assignments.

Knot validation checks finite coordinates and board bounds, minimum stone separation, segment intersections and distance from each unrelated stone to a thread. A clear board can use any valid arrangement; it need not match the generator's clean layout. The intersection test now distinguishes disjoint collinear segments from actual overlapping/touching segments.

Property tests cover 600 instances of each family, correct/invalid answers, unique witness assignments, unique offering combinations, maze route uniqueness, all 512 lantern states, the minimum knot difficulty, distinguishable polygon rules, six-shard uniqueness and a unique approximate geometric match for star charts. Local/hosted integration remains responsible for stable assignments and once-only rewards.

## Reference context

The classic truth/lie genre is **Knights and Knaves**, popularized by Raymond Smullyan: knights always tell the truth and knaves always lie. Our three-statement, two-true/one-false version is an adaptation rather than the standard islander-identification setup. [Carnegie Mellon logic teaching examples](https://www.andrew.cmu.edu/user/scheines/80-110/lectures/mar12/mar12.htm).

The constellation drawings are original simplified game diagrams of recognizable star patterns, not astrometric maps or reproductions of source artwork. Reference identities/charts: [IAU Cassiopeia](https://iauarchive.eso.org/public/images/detail/cas/), [IAU Corona Borealis chart](https://iauarchive.eso.org/static/public/constellations/pdf/CRB.pdf). Star spacing and the reference remain consistent within each generated puzzle. Real-device timing will determine whether the seven-star version needs fewer distractors.

# Session handoff template
Copy into `workstreams/<family>/<task>/handoff-YYYY-MM-DD.md` or the appropriate existing task folder. Use a unique suffix for two sessions on the same day.

- Session title and ID:
- Updated date:
- Scope / owned files:
- Checkout, branch and base commit:
- Status: complete / ready to continue / blocked:
- Confirmed user decisions (include source/date):
- Proposals awaiting a decision:
- Completed work and canonical file links:
- Checks actually run and results:
- Purchases / external changes / deployments actually performed:
- Remaining work in priority order:
- Dependencies on sibling tasks:
- Unpersisted conversation details or access limitations:
- Commit(s), integration status and remaining unrelated dirty files:

Save this before the final commit. Report the resulting commit hash in the session's final response; don't repeatedly amend the file just to insert its own hash. Historical chat-only details should be reconciled against current files before becoming requirements.

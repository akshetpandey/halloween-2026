## Routes and continuity

- `https://hollow-court.com` serves `hollow-court-preview` through a Cloudflare Custom Domain, with managed DNS/TLS. The workers.dev URL stays available.
- `/r` and `/R` issue a temporary 302 redirect to the configured Partiful event. Query parameters never choose a different destination. This short address lets the printed QR survive a future Partiful destination change.
- Summons use `/s/<code>`; `/S/<code>` is also supported. Twelve random Base32 characters carry 60 bits of randomness. A unique D1 index and conditional updates protect against collisions/concurrent assignment. Aliases are bearer invitation links, not account recovery credentials.
- Additive migration `0003_short_summons.sql` preserves each original 32-character invitation token and adds `short_code`. A missing alias is allocated on the inviter's next state read. Both forms resolve to the original invitation before atomic registration/redemption, preserving single use and attribution. Existing old links remain valid.
- QR values use uppercase scheme/host/path only on the two supported short routes. Uppercase URL spelling permits alphanumeric QR encoding. Legacy token spelling remains untouched. Copyable links use conventional lowercase scheme/host/path and the case-sensitive alias.
- Browser cookies belong to their hostname. Existing workers.dev sessions continue there; use the existing recovery flow to restore the same account on the new domain. Photos, Favors, accounts and retention behavior are unchanged.

## Artwork and error correction

The QR overlays the generated woodland illustration with subtly tinted cells and small high-contrast centers. Finder/timing/alignment/format modules remain visible; a bounded 5×7-module central window exposes the illuminated oak doorway while preserving any structural modules inside it. A four-module quiet zone surrounds the image. No QR payload is generated by the image model: the `qrcode` library encodes the actual destination deterministically.

Level **Q** replaces H. At these uppercase payload lengths, M gives the same dimensions as Q, so reducing further would sacrifice correction without reducing density. Partiful is now **25×25** modules (formerly 37×37); short Summons are **29×29** (formerly 53×53 on the configured workers.dev address). The lower L level could shrink a Summons further, but leaves less room for the illustration. Q is the selected compromise, verified in software; actual camera testing remains necessary.

The scene is a generated original, not a copy of the reference illustration. Asset: [woodland-portal.webp](src/client/assets/woodland-portal.webp), optimized from the built-in image tool output to a 1000px WebP. [Artwork prompt](src/client/assets/README.md). The asset is served separately from the JavaScript bundle.

Tests rasterize the actual SVG including its artwork, decode at 244px and 488px, and exercise varied synthetic aliases with mild optical blur. Integration tests cover short and original token redemption racing for the same Summons, alias stability, redirects, preserved Favors and portrait storage. Software decoding does not establish real-camera performance under party lighting.

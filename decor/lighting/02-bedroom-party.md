# Hollow lights — budget two-fixture plan

Updated October 21, 2026. Selected proposal: [U'King 36 LED RGB PAR, 2 Packs, B0B9H16RH5](https://www.amazon.com/dp/B0B9H16RH5), **$39.99/kit**, checked in signed-in Chrome earlier October 21 with latest Oct 24 conditional delivery. Two fixtures total, brackets/remotes listed, actual contents/control batteries inspected on receipt. This replaces the old $150–250 rental/$259.98 premium purchase baseline.

One red/amber skim reveals guardian face and branches; one violet/blue surface wash gives depth against all-wall black velvet. Place at protected perimeter on supported factory brackets, clear of fabric and the side route. Keep useful door/controls light; black fabric absorbs light, so test angles before increasing output.

Listing offers microphone sound-active mode. It responds to sound, not the DJ beat grid. Color restriction, sensitivity, fan noise, strobe-free behavior and power-cycle memory in that mode remain untested. Try at real music volume; if unsuitable retain low static red/violet with strobe disabled. No laser, fog, rapid-strobe requirement, software sync, controller/interface or extra fixtures in the basket.

Guardian eyes use a separate **steady warm USB string** with two diffused clusters; body gets PAR changes. This keeps eyes readable if a sound program changes color. Leave string intact; test complete assembly/temperature, controls and nine-hour operation. Record exact remote mode/settings and manual normal-light reset.
